# Algerian Wilayas GeoJSON

- **File**: `algeria-wilayas.geojson`
- **Scope**: 58 Algerian Wilayas (`01` through `58`) matching the official administrative division codes.
- **Source**: [fr33dz/Algeria-geojson](https://github.com/fr33dz/Algeria-geojson)
- **License**: MIT / Open Geographic Data
- **Properties**: Each feature includes `code` (e.g. `"16"` for Algiers / Alger), `name`, `name_ar`, and `name_ber`.
